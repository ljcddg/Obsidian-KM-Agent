# Feature · Learning Roadmap（学习路线生成）

> 目标：输入一个学习目标（如"我要学 Java 并发"），自动生成**带前置依赖排序的学习路线**，每个节点对应一篇笔记，路线本身沉淀为 MOC 的学习路线章节。

## 触发时机

用户提出学习目标类请求："我要学 XX""XX 应该按什么顺序学""帮我规划 XX 的学习路径"。

## 执行流程

### Step 1 · 目标拆解

把大目标拆成主题清单（3~8 个），每个主题对应一个可写笔记的粒度（L1/L2/L3 级别）。

示例：目标"Java 并发" →

```
线程基础（L2） → synchronized（L2） → volatile（L2） → AQS（L3）
→ CountDownLatch/CyclicBarrier（L2） → 线程池（L2） → CompletableFuture（L2）
```

### Step 2 · 依赖排序

按"前置依赖"拓扑排序，保证路线里每个节点学它之前的节点都已覆盖：

- 规则：A 依赖 B → B 排在 A 前面。
- 同一层可并行的节点标注"可并行"。

### Step 3 · 分级标注

每个节点标注建议的笔记等级（L1/L2/L3）与重要程度（星数），供后续写笔记时直接取用。

### Step 4 · 产出路线（两种形式）

**形式 A：路线图（放 MOC 的学习路线章节）**

```markdown
## 学习路线：{{主题}}
1. [[{{节点1}}]] —— {{为什么先学它}}
2. [[{{节点2}}]] ← 依赖 {{节点1}}
3. [[{{节点3}}]]（可并行：[[{{节点3b}}]]）
4. ...
```

**形式 B：mermaid 依赖图**

```mermaid
graph TD
    A[{{节点1}}] --> B[{{节点2}}]
    B --> C[{{节点3}}]
    C --> D[{{节点4}}]
    C --> E[{{节点5}}]
```

### Step 5 · 落地

- 已有笔记的节点：直接链接。
- 没有的节点：创建占位链接 `[待创建]`，登记进 MOC，作为后续写作清单。
- 把路线写进 MOC 的"学习路线建议"章节，成为长期导航。

## 输出规范

- 路线节点数 3~8 个为宜，过多就分层（主线 + 支线）。
- 每个节点一句话说明"为什么在这个位置"（依赖关系/难度递进）。
- 路线可迭代：学完一段后回头更新 MOC，删掉完成的、补充新发现的。
