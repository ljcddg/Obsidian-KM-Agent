# Feature · Interview Mode（面试复习模式）

> 目标：把知识库变成**面试训练场**——从已有笔记生成面试题、闭卷自测、薄弱点定位，考前快速拉练。

## 触发时机

用户要求"面试复习""出面试题""模拟面试""考前冲刺"；或日常复习时切换为提问模式。

## 三种用法

### 用法一 · 出题自测（单篇 → 题库）

从指定笔记（或 MOC 下全部笔记）生成面试题：

1. 按笔记的"自测题"章节抽取，没有则按笔记内容现场出题。
2. 题型分布：简答（讲原理）40% + 辨析（A/B 区别）30% + 场景题 30%。
3. 按 `importance` 过滤：考前冲刺只出 ⭐⭐⭐⭐ 以上。

输出格式：

```markdown
## {{主题}} 面试题（共 8 题）
1. 为什么需要 {{核心概念}}？（⭐⭐⭐⭐⭐）
2. {{A}} 与 {{B}} 的区别？（⭐⭐⭐⭐）
3. 场景：{{场景}}，该选哪个，为什么？（⭐⭐⭐）
...
```

### 用法二 · 闭卷默写（复习时用）

- 盖住笔记正文，只留标题，让用户默写"为什么 / 核心机制 / 对比维度"。
- 对照订正后更新掌握状态与生命周期 `status`（递进与回退规则见 `references/learning-system.md`）。

### 用法三 · 薄弱点定位（考前拉练）

- 用户作答后，把答错的题映射回对应笔记，列出"薄弱笔记清单"。
- 输出复习优先级：`薄弱点 → 对应笔记 → 建议复习动作`。

```markdown
## 薄弱点分析
| 答错的知识点 | 对应笔记 | 薄弱类型 | 建议 |
|-------------|---------|---------|------|
| AQS 原理 | [[AQS知识点]] | 机制不清 | 重读"为什么"节 + 闭卷默写 |
```

## 高频题维护

- 面试中被问过/查过的高频题，在笔记"自测题"里加 ⭐ 标注，作为复习重点。
- 一个主题攒够 10+ 高频题 → 升级为 L3 专题，配 mermaid 图与对比表。

## 与复习系统的联动

- 面试模式发现的薄弱笔记 → 把 `next_review` 提前到今天。
- 连续通过（能讲解）的笔记 → 按 `learning-system.md` 正常降频。
